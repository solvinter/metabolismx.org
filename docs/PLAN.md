# Metabolism X - definite plan of action

## övergripande syfte

Bygga Metabolism X som en tydlig och trovärdig plattform med två första riktningar
  1. ### Screening för personer som bryr sig om sin hälsa
     Erbjuda vägledningkring metabola markörer, screening och förståelse.
  2. ### Utlåtande / bedömninng
     liksom företagshälsovård remittera avvikanden fynd till vårdcentral inligt nationella riktlinjer.
  3. ### Företabshälsovård light
     Erbjuda företag utan etablerad företagshälsovård ett enklare, mer tillgänlgigt alternativ.


### Projektet mynnar ut i:
- en hemsida
- ett tydligt erbjudande
- en folder till allmänhet
- en folder till företag
- webversion av boken
- manus, essäer, artiklar etc
- en konkret go-to-market-sturktur

2. ## Erbjudanden

Brut ut erbjudandet i tydliga produkter/tjänster

# A. Individspåret
Mål: hjälpa personer som vill förstå sina metabola markörer och risker bättre.

Exempel på innehåll:
- introductionssamtal / screening
- genomgång av metabolab markörer
- pedagogisk återkoppling
- rekommendationer om nästa steg

# B. Företagsspåret
Mål: erbjuda företag ett lättare, enklare alternativ där klassisk företgshälsovård saknas.

Exempel på innehåll:
- enkel hälsoscreening för anställda
- basal metabol risköversikt
- pedagogisk sammanställning
- eventuell föreläsning / uppföljning
