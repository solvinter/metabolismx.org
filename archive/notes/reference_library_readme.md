# Referensdatabas för VS Code och MetabolismX.org

## Filer
- `referenser_master.csv`: huvuddatabas för redigering och filtrering i VS Code
- `referenser_master.json`: strukturerad export för webb/automation
- `referenser_bilaga.md`: manusvänlig bilageversion (numrerad lista)

## Rekommenderat arbetssätt
1. Filtrera/sök i `referenser_master.csv` per kapitel (K8/K9/K10).
2. Markera `in_manus=ja` för referenser du faktiskt använder.
3. Exportera urvalet till kapitelvisa referenslistor inför slutredigering.
