# Active Reference Library for Metabolism X v3

Denna mapp ar det aktiva strukturerade referensbiblioteket for `Metabolism_X_v3`.

## Innehall

- `referenser_master.csv`
- `referenser_master.json`
- `referenser_master_readable.yaml`
- `referenser_master_strict.yaml`
- `referenser_bilaga.md`
- `referenser_missing_report.md`

## Status

- Biblioteket ar importerat fran `Obsidianutkast` i `dominic_os`.
- Det innehaller 72 dataposter.
- Det ska betraktas som huvudkalla for referensarbete i `v3`.

## Arbetsprincip

- Den renare manusversionen `MetabolismX_manus_v2` visar vilka referenser som var explicit aktiverade dar.
- Masterbiblioteket ar bredare och ska anvandas som forskningsreserv och aktivt underlag for nya kapitel i `v3`.
- Eventuell framtida synkning med `dominic_os` ska ske medvetet, inte genom tyst divergens.
